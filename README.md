☕ BRUM — Votre café, à votre façon

BRUM est une application web interactive de personnalisation de café qui permet aux utilisateurs de créer leur café idéal ou de découvrir des recommandations personnalisées.

Du choix de la base du café à la sélection des ingrédients, BRUM offre une expérience intuitive permettant à chacun de composer une boisson selon ses préférences.

### Fonctionnalités

* Personnalisation du café — Créez votre café en choisissant les options et les ingrédients souhaités.
* Recommandations personnalisées — Découvrez des suggestions de cafés adaptées à vos préférences.
* Calcul dynamique des prix — Le prix total s’actualise automatiquement selon les choix effectués.
* Panier — Ajoutez vos créations au panier et consultez vos sélections.
* Récapitulatif de commande — Consultez un récapitulatif détaillé de votre café personnalisé.
* Modification des sélections — Modifiez votre création avant de finaliser votre commande.
* Interface d’administration — Une interface dédiée à l’administration du site.

## Technologies utilisées

* HTML5 — Structure et organisation du contenu.
* CSS3 — Mise en forme, disposition et design responsive.
* JavaScript (Vanilla JS) — Logique applicative et manipulation du DOM.
* Tailwind CSS — Framework CSS basé sur des classes utilitaires.
* Google Fonts — Gestion de la typographie.

## Concepts et notions JavaScript abordés

Ce projet constitue également une mise en pratique des fondamentaux de JavaScript, notamment :

Manipulation du DOM

* querySelector() et getElementById()
* Différences entre NodeList, HTMLCollection et éléments HTML
* classList, className et cssText
* Propriétés des éléments HTML et dataset
* Gestion des événements et écouteurs d’événements

## Concepts JavaScript

* Debouncing
* Encodage des URL
* Local Storage
* Session Storage
* Gestion des interactions utilisateur

### Objectifs pédagogiques

BRUM est bien plus qu’un simple site de personnalisation de café : c’est un projet pratique permettant de consolider les connaissances fondamentales en JavaScript.

Le développement de ce projet met l’accent sur l’interaction entre JavaScript et les éléments HTML, la gestion des événements, l’utilisation du stockage du navigateur ainsi que l’organisation du code.

### Améliorations envisagées

* Améliorer la lisibilité et la maintenabilité du code.
* Refactoriser les fonctions selon le principe de responsabilité unique (Single Responsibility Principle).
* Réduire les boucles imbriquées inutiles.
